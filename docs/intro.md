# Agentic Infrastructure as Code

> Plan, build, verify, and govern infrastructure changes with AI agents. — by Gourav Shah, School of DevOps & AI.

A project-based course for infrastructure engineers who want to use AI agents safely. You build a small production-style AI workload platform with local Terraform, Kubernetes, Helm, GitOps, and clear human approval gates.

## Who this is for

DevOps, platform, SRE, cloud and infrastructure engineers, plus software and AI engineers who need to create and operate infrastructure as code safely with AI agents.

## How to use this course

Each section combines focused concept videos, technical slides, a guided lab, an operator challenge, and a quiz. Work through them in order. The same compact production AI workload platform grows across the course, with one governed and reviewable capability added in each section.
